# Ramesh Nerella — Portfolio

Personal portfolio site for **Ramesh Nerella**, Senior UI Developer / Technical Lead.

**Live:** https://rameshneralla.github.io/portfolio/

## About

A single-page static portfolio built with **HTML5**, **CSS3**, and **Bootstrap Icons**, with
[particles.js](https://vincentgarreau.com/particles.js/) and [Swiper](https://swiperjs.com/) loaded
from CDN. No build step, no framework, no package manager.

- `index.html` — the entire page markup
- `style.css` — all styles (theming via CSS custom properties, dark/light modes)
- `images/` — profile photo, company logos, QR code
- `resume/Ramesh_Resume.pdf` — downloadable résumé

## Run locally

Open `index.html` directly in any browser — no dev server needed.

## Deploy

Hosted on **GitHub Pages** from the `main` branch (root). Pushing to `main` publishes the site.
